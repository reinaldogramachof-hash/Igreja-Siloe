# Ordens de trabalho

Uma OT por tarefa, arquivo `OT-<ID>.md`, criada a partir de
`../templates/ORDEM-DE-TRABALHO.md`.

- O **Arquiteto** redige a OT quando o Orquestrador seleciona o ID para um ciclo.
- **Reinaldo** aprova antes da execução: Tipo 1 item a item; Tipo 2 em lote no
  início do ciclo.
- A OT fica versionada aqui como registro — a aprovação é a linha assinada no
  fim do arquivo.
- Um agente só entra em `Execucao` no `BACKLOG-OPERACIONAL.md` depois que a OT
  correspondente está aprovada.
